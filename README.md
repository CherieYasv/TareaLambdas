# TareaLambdas
En este proyecto se buscará evaluar las correctas validaciones, uso de lambdas, de cadenas y la complementación de todos estos elementos en diferentes problemas con cada uno diferentes soluciones y diferentes clases y métodos que deberemos importar y utilizar. 

# Lista de los 10 métoodos:
-> multiplicarElementos
Se trata de un método encargado de tomar una lista y regresar con sus elementos multiplicados por un valor que recibe.

-> eliminarPorLetraOLongitud
Se trata de un método encargado de recibir como parametro una letra, longitud y la lista, y eliminar todos los valores que tengan esa longitud o que comiencen con esa letra.

-> convertirAMayusculas
Se trata de un método que, usando Stream y map, se buscara pasar a mayuscula las palabras de la lista.

-> cuadradosParesUnicos
Se trata de un método encargado que toma una lista de numeros enteros, toma unicamente los valores que no esten duplicados y sean paes, y los eleva al cuadrado.

-> mapearPalabraALongitud
Se trata de un método que toma las palabras de una lista y regresa una lista donde la clave sea la palabra y el valor sea la longitud de la misma.

-> imprimirCatalogoConDescuento
Se trata de un método que recibe una lista de productos con sus precios y regresa una lista donde se muestra el catalogo de los productos con un descuento del 10%

-> contarFrecuencias
Se trata de un método que toma palabras de una lista y te devuelve cuantas veces se repitió/apareció cada palabra

-> filtarPorFrecuenciaMenor
Se trata de un método que toma palabras de una lista y un minimo de longitud, y filta la lista deacuerdo a la cantidad minima de letras que debe contener.

-> deduplicarPalabras
Se trata de un método que toma una frase larga y filta las palabras con menos de N letras, convertirlas a minusculas y guardarlo, asegurando que no haya repetidas.

-> limitarFrecuencia
Se trata de un método que toma palabras y frecuencias y limita todas las frecuencias a un maximo de N. Si una frecuencia es mayor a N, debe fijarse exactamente en N mediante una lambda.



# Instrucciones de compilacion:
1. Contar previamente con java openjdk 27 o superior.
2. Descargar "cadenas.java", "numeros.java" y "Main.java" y colocarlos en una misma carpeta.
3. Ejecutarlo con su IDE de confianza. O respectivamente:
   Para ejecutar en cmd o Powershell de Windows, colocar estos 3 comandos por separado:
     cd C:\ruta\a\tu\carpeta
     javac -encoding UTF-8 Main.java
     chcp 65001
     java -Dfile.encoding=UTF-8 -Dstdout.encoding=UTF-8 Main
  Para ejecutar en la terminal de Linux, colocar estos 3 comandos por separado:
    cd /ruta/a/tu/carpeta
    javac -encoding UTF-8 Main.java
    java Main
